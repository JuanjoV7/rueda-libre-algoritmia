Pasos para alquilar una bicicleta

1. El cliente busca la bicicleta que se acomode a sus necesidades
2. Si se acomoda a sus necesidades entonces
3. Informa al encargado
4. Se revisa la bicicleta
5. Se informa al cliente su estado
6. Se pide el documento para alquilar
7. Se hace el cobro
8. Se entrega la  bicicleta, casco y candado
9. El cliente se retira con la bicicleta, casco y candado
10. Sino, el encargado informa cuando habrá disponibilidad
11. El cliente se retira
12. Finaliza el proceso

Ejemplo: 

- El cliente ingresa al negocio,  observa entre las bicicletas disponibles y busca
la que se acomode a sus necesidades, informa al encargado y el encargado revisa 
el estado de la bicicleta, pide su documento para alquilar y le realiza el cobro.
Entrega la bicicleta con el casco y el candado, el cliente se retira con su producto y finaliza el proceso.
